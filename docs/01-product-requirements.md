# 产品需求与验收标准

> 版本：0.1.0
> 状态：基线需求，后续变更必须通过决策记录追踪。

## 1. 用户与场景

### 1.1 个人开发者

用户在本机同时使用不同供应商的 coding Agent，希望从 CLI 或桌面端创建任务，让多个 Agent 分别进行分析、实现、测试和审查，并能在一个会话中查看交接过程。

### 1.2 办公工作者

用户在工作模式中处理邮件、文档、表格和审批类任务，希望通过飞书、钉钉、企业微信或自研 App 发起任务、获取进度、人工确认高风险步骤并查看结果。

### 1.3 远程用户

用户离开电脑后，通过手机浏览器或聊天渠道查看某个任务的状态、最近事件、待审批事项和失败原因；高风险动作默认只能在本机批准。

## 2. 核心概念

- **工作区 Workspace**：代码、文档、配置和记忆的隔离边界。
- **会话 Session**：用户与一个或多个 Agent 围绕同一目标的持续交互。
- **任务 Task**：可暂停、恢复、取消、重试并有状态的工作单元。
- **运行 Run**：任务的一次执行尝试，关联 Agent、工具、沙箱和资源配额。
- **事件 Event**：系统中的事实记录，支持实时推送和历史重放。
- **能力 Capability**：Agent 或扩展可执行的动作声明，例如读文件、运行命令、联网。
- **记忆 Memory**：带来源、范围、置信度、时间和生命周期的可检索知识。
- **审批 Approval**：需要用户明确判断的策略闸门。

## 3. 功能范围

### P0：核心可用产品

1. 本地运行时启动、健康检查、优雅关闭和崩溃恢复。
2. 创建工作区、会话、任务和运行；任务状态可暂停、取消、重试。
3. 统一事件模型和实时流；CLI 能创建任务并订阅进度。
4. 通过稳定的进程适配器接入至少一个 JSONL/stdio Agent，并保留 Codex、Claude Code、Cursor 的适配接口。
5. Agent 能声明能力，工具调用经过策略判断、超时、输出限制和审计。
6. 工作模式与代码模式使用不同默认策略、提示模板、工具集和审批门。
7. 记忆支持全局、工作区、会话三层范围，支持明确保存、检索、删除和导出。
8. Agent 可创建子任务并向其他 Agent 委派；父子任务有可追踪关联。
9. CLI 提供任务创建、查看、跟随、审批、取消、导出等基础命令。
10. 本地 HTTP/WebSocket API 为桌面端、PWA 和渠道适配器提供统一接口。

### P1：多端和生态

1. 桌面端展示工作区、会话、任务时间线、事件详情、记忆和审批。
2. 手机友好的只读进度页和审批页，默认绑定本机且短时令牌可撤销。
3. MCP 客户端能力：发现服务器、列出工具/资源/提示词、调用工具并审计。
4. 插件、技能、规则、命令和钩子使用版本化清单和权限声明加载。
5. 飞书、钉钉、企业微信使用 webhook/机器人适配器，并有去重和签名校验。
6. 自研 App 通过版本化 REST/WebSocket API 接入。
7. 工作流支持串行、并行、条件、人工审批、超时和补偿。

### P2：高级能力

1. 多模型路由、成本/延迟/能力策略和供应商故障转移。
2. 语义记忆索引与混合检索；敏感记忆隔离和保留策略。
3. 受限网络沙箱、容器/虚拟机执行后端和可复现实验环境。
4. A2A 等 Agent 间协议的实验性网关，协议能力不进入核心领域模型。
5. 任务计划、定时触发、外部事件触发和长期运行守护。
6. 自动化评测、回放、质量评分和自进化提案；所有自动修改仍需策略和审批。

## 4. 非功能需求

- **可靠性**：进程崩溃后不丢失已提交事件；运行可以从最后检查点恢复。
- **性能**：本地 API 在 100 个并发事件订阅下保持可用；事件追加不因单个 UI 客户端阻塞。
- **隐私**：凭据使用系统密钥链或加密存储；日志和记忆默认脱敏。
- **安全**：默认拒绝网络、写入工作区之外、执行高风险命令和访问凭据。
- **可迁移**：导出包包含 JSONL 事件、配置、记忆和版本信息；可校验完整性。
- **可观察**：每次运行有 correlation ID、耗时、状态、错误分类和资源用量。
- **兼容**：外部适配器版本、探测结果和失败原因可见，不把不可验证能力标记为已支持。

## 5. 验收证据

| 要求 | 权威证据 |
| --- | --- |
| 核心领域模型 | `packages/domain` 类型检查、事件序列化测试 |
| 任务生命周期 | 状态机单测、恢复/取消/重试集成测试 |
| Agent 接入 | 真实 JSONL/stdio fixture 与适配器兼容性测试 |
| 记忆 | 保存、检索、删除、导出测试和数据范围测试 |
| 安全边界 | 策略矩阵测试、拒绝事件、敏感信息测试 |
| CLI | CLI 端到端测试和命令帮助输出 |
| 远程查看 | API/WebSocket 认证、断线重连和只读权限测试 |
| 渠道适配 | webhook 签名、幂等、限流和错误回执测试 |
| 桌面端 | 构建、启动、任务时间线和审批流程测试 |
| 文档与图表 | 文档索引、SVG 可打开、架构与实现保持一致 |
