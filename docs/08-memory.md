# 全局记忆

> 版本：0.1.0

## 范围与原则

`packages/memory` 提供可审计的记忆基础能力：

- `global`：跨工作区共享的用户偏好和长期事实
- `workspace`：只对一个工作区可见
- `session`：只对一个工作区中的一个会话可见
- `public`、`private`、`secret`：敏感度标记；`secret` 默认不参与检索
- 来源为 `user`、`agent` 或 `system`，可关联来源事件
- 支持置信度、过期时间、软删除和 JSONL 导出

检索当前使用确定性的关键词重叠评分，并按置信度和更新时间排序。它故意没有把生成式摘要或向量嵌入藏在存储层，后续可以通过同一个 `MemoryService` 接入 SQLite FTS5 或本地向量索引。

## 使用边界

工作区和会话上下文必须显式传入。工作区不匹配时，工作区/会话记忆不可见；全局记忆仍可见。秘密记忆只有在调用方明确设置 `includeSensitive` 时才可检索，这个选项仍应受运行时策略控制。

自动从 Agent 输出提取的事实不能直接调用 `save` 形成持久记忆；正式运行时应先写入候选区，经过用户确认或满足可验证规则后再提升为记忆。删除采用可追踪的 tombstone，避免恢复或备份时悄悄复活已删除数据。

## 当前限制

- 当前存储是 JSONL，适合基线和导出；生产长期运行需要 SQLite 事务、索引、备份和迁移。
- 当前检索是关键词匹配，不能替代语义检索。
- 当前没有自动秘密识别和加密字段；敏感数据仍应由策略和密钥链边界保护。
