# 安全与威胁模型

> 版本：0.1.0

## 1. 保护对象

- 用户源代码、文档、消息和个人数据
- Agent 凭据、API 密钥、OAuth 刷新令牌和系统密钥链引用
- 会话上下文、全局记忆、任务结果和审计日志
- 本机文件系统、命令执行权限、网络访问和外部渠道身份

## 2. 主要威胁

1. 提示词注入诱导 Agent 泄露上下文、执行越权工具或修改策略。
2. 恶意或被攻陷的 MCP 服务、插件、技能包和外部 Agent。
3. 渠道 webhook 重放、伪造消息、权限混淆和账号接管。
4. Agent 生成的高风险命令、恶意依赖、数据外传和破坏性修改。
5. 本地 HTTP 端口暴露、远程令牌泄漏、日志泄露和备份泄露。
6. 自动提取记忆把秘密、错误结论或跨工作区信息长期保存。
7. 供应商升级改变 CLI 输出或工具语义，造成静默错误。

## 3. 安全控制

- 能力清单、工作区路径白名单、命令风险分类和默认拒绝。
- 工具调用前策略检查；策略结果、理由和审批人写入审计事件。
- 外部输出视为不可信数据；系统指令、用户指令和工具数据分层传递。
- Agent、插件和 MCP 服务使用独立进程、超时、输出大小限制和取消信号。
- 远程访问默认关闭；开启时只暴露最小 API，令牌短期、可撤销、可审计。
- 渠道消息使用签名/时间戳/nonce/幂等键校验，并按租户和会话隔离。
- 凭据不进入 prompt、事件正文、调试日志、记忆或导出包。
- 自动记忆先进入候选区；敏感内容分类、过期和删除可追踪。
- 每次适配器探测记录供应商、版本、协议、能力和兼容性结果。

## 4. 沙箱分级

| 级别 | 适用 | 默认能力 |
| --- | --- | --- |
| S0 | 纯规划/文本 | 无文件写入、无网络、无命令 |
| S1 | 代码读取和分析 | 只读工作区、无网络 |
| S2 | 本地测试 | 临时写目录、有限命令、无凭据、默认无网络 |
| S3 | 受控集成 | 明确网络出口、临时凭据代理、人工审批 |
| S4 | 高风险/未知扩展 | 隔离容器或虚拟机、一次性工作区、强制人工批准 |

S0-S2 可以先由本地策略实现；S3-S4 必须依赖经过验证的操作系统或容器隔离，不用“提示词约束”冒充沙箱。

## 5. 安全验收

安全功能必须有拒绝路径测试，而不仅是成功路径测试。每个工具能力至少验证：无权限、越界路径、超时、超大输出、恶意参数、取消、重试幂等和审计记录。
