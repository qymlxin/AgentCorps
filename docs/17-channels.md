# 聊天渠道适配

> 版本：0.1.0

## 统一边界

`packages/channels` 将飞书、钉钉、企业微信和自研 App 的 webhook 输入归一化为 `InboundMessage`。飞书事件、钉钉机器人消息和企业微信明文消息现在有独立适配器；平台回调签名算法和消息格式均有本地 fixture。企业微信加密 XML 的 AES 解密、平台回调响应和真实账号探测仍属于部署前验证项。

渠道入站去重、会话映射和投递状态可以通过 `SqliteChannelStateStore` 持久化；默认内存实现仅适合开发和测试。

## 安全基线

- `verifyHmacSha256` 提供签名验证基础，具体渠道的时间戳/nonce 算法由专用适配器实现。
- `MessageDeduplicator` 防止 webhook 重试重复创建任务或消息。
- 外部身份必须映射到本地用户/设备/会话，不能仅凭文本里的用户名称授权。
- 原始 payload 是不可信输入，必须限制大小、字段和附件类型，并在日志中脱敏。

当前实现是规范化与安全基础包，还没有声明已连接真实飞书、钉钉或企业微信账号。正式渠道适配器必须使用各平台当前官方签名、机器人发送和限流文档建立 fixture 测试。
