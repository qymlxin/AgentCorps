# Signal Room 控制台

> 版本：0.1.0
> 目录：`apps/console`

## 运行

先启动本地网关：

```bash
node apps/cli/dist/index.js serve --port 43210 --data-dir ~/.agentcorps
```

再启动静态控制台：

```bash
pnpm --filter @agentcorps/console dev
```

浏览器打开 `http://127.0.0.1:4173`。控制台默认连接 `http://127.0.0.1:43210`，可以在设置中修改 API 地址和 Bearer 令牌。

## 已实现

- 本地运行时健康状态
- 当前任务、模式、状态和目标
- 会话数量与事件数量
- 任务时间线和实时 SSE 更新
- 新建 code/work 任务，并选择已有会话
- 本地存储连接配置
- 移动宽度响应式布局、PWA manifest 和离线静态 shell 缓存
- 审批队列状态显示，并在网关允许时提供批准/拒绝操作
- `apps/desktop` 提供 Tauri 2 桌面壳，复用同一控制台和本地网关；桌面打包仍需要目标机器安装 Xcode/平台构建工具

控制台只是控制面，不执行 Agent 命令；所有任务创建、运行和事件读取都经过网关。远程模式需要网关显式开启令牌和 CORS，控制台不会把令牌写入仓库。

## 设计方向

界面采用深色的运行控制台视觉：酸绿色表示可操作和在线状态，橙色表示风险或异常，衬线大标题把“长期上下文”与密集的事件数据区分开。布局优先展示任务状态和事件证据，而不是聊天气泡。
